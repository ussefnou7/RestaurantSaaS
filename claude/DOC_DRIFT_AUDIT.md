## Audit rules used

- `BUILT` means entity/repository, non-trivial service behavior, permission-protected controller,
  and test references exist. Infrastructure packages (`common/`, `config/`) are marked built when
  their runtime components are wired and tested; the entity/controller rubric does not apply to
  them.
- `SCAFFOLDING` means persistence types or a frontend shell exist without an operational backend
  service/controller/test path.
- Frontend evidence requires a page, a router entry, and a real service call. A frontend that calls
  an endpoint absent from the backend is explicitly reported as a non-operational shell.
- An absence finding is based on a repository-wide symbol/content search across `src/main/java`,
  `src/main/resources/db/migration`, and `src/test/java`; absence cannot have a positive source line.
- Controller lists below name exposed controller surfaces. Permission exceptions discovered during
  the pass are called out rather than silently treating authentication as a permission annotation.
